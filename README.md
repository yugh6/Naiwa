# 奶蛙桌宠

**原始素材版 · v1.2.2**

一款运行在 Windows 桌面上的奶蛙桌宠，使用原始图片和视频素材。本分支增加全桌面目光跟随、摸头反馈和文件投喂，并保留眨眼、戳肚子、拖动和原版大笑。

## 运行环境

- Windows 10 / 11。
- .NET Framework 4.x。
- 本地运行，无需联网。

## 启动方法

1. 将 `奶蛙桌宠.exe`、`素材.nwp` 和 `原版笑声.wav` 放在同一个文件夹中。
2. 双击 `奶蛙桌宠.exe` 启动；如果已有桌面快捷方式，也可以通过快捷方式启动。
3. 右键奶蛙或任务栏托盘中的奶蛙图标，打开设置菜单。

重复启动不会出现多个奶蛙，而是让已有的奶蛙回到鼠标所在屏幕的右下角。

## 交互方式

| 操作或场景 | 效果 |
| --- | --- |
| 待机 | 保持原图形象，约每隔 4～8 秒自然眨眼。 |
| 在桌面移动鼠标 | 可见眼睛内的瞳孔平滑跟随上下左右方向；关闭「目光跟随鼠标」后，恢复原来的移入转眼、移开复原。 |
| 单击头部 | 头部轻轻下压、低头眨眼，再弹回复原，整个摸头反馈约 0.85 秒。 |
| 单击肚子 | 肚子明显凹下，再弹起并轻晃复原，整个反馈约 1 秒。点击其他部位不会戳肚子。 |
| 双击肚子 | 播放约 14 秒的原版捧腹大笑，包含最后笑倒的动作；双击其他部位不会触发大笑。 |
| 笑倒后单击 | 恢复站立待机；不点击则保持躺姿。 |
| 把本地文件拖到奶蛙身上 | 确认后送入系统回收站；成功后显示纸张飞入口和肚子反馈，失败会说明原因。 |
| 按住左键拖动 | 移动奶蛙，随移动方向轻微倾斜；松手后轻弹一下，并记住新位置。支持拖到另一块屏幕。 |
| 所在屏幕的前台应用进入全屏 | 自动隐藏奶蛙并停止笑声；退出全屏或切走该应用后，在原位置恢复。 |

大笑播放期间再次双击不会叠加播放。可以通过右键菜单随时停止，开始拖动也会中断当前大笑。

## 右键菜单

右键奶蛙或托盘图标，可使用以下功能：

| 菜单项 | 用途 |
| --- | --- |
| 捧腹大笑 | 播放原版大笑，也可双击肚子触发。 |
| 停止大笑 / 站起来 | 停止正在播放的大笑，或让躺着的奶蛙恢复站立。 |
| 原版笑声 | 开启或关闭大笑原声。 |
| 大小 | 选择小号、标准或大号。 |
| 总在最上面 | 开启或关闭窗口置顶。 |
| 全屏时自动隐藏 | 开启或关闭全屏隐藏功能。 |
| 目光跟随鼠标 | 默认开启；关闭后恢复原版悬停转眼。 |
| 投喂文件前确认 | 默认开启；每次投喂前列出文件并确认，可按需要关闭。 |
| 回到屏幕右下角 | 将奶蛙移回鼠标所在屏幕的右下角。 |
| 打开使用说明 | 打开随程序附带的文本说明。 |
| 退出奶蛙 | 关闭桌宠。 |

**开关菜单项右侧有 ✓ 表示开启，没有对勾表示关闭。**

## 文件投喂

- 只接收本地固定磁盘上的普通文件，一次最多 100 个；暂不接收文件夹、网络位置、U 盘、链接、云端占位文件及系统或程序安装目录中的文件。
- 拖到奶蛙身上可看到接收提示，移开即取消；默认松手后还需确认一次。
- 文件通过 Windows 系统回收接口处理，可以从回收站还原。不能回收时会停止该文件的操作，不改用永久删除。
- 只对确认回收成功的文件显示吞食反馈。批量投喂若部分失败，会分别报告成功数量和未完成原因。
- 回收进行中不能重复投喂或退出；完成后可继续互动。

## 原版笑声

首次使用默认关闭笑声，升级时保留原来的设置。

- 勾选「原版笑声」后，下次开始大笑时会同步播放原声。
- 播放中关闭笑声，会立即静音。
- 播放中开启笑声，会在下一次大笑时生效，避免声画错位。
- 拖动、手动停止或全屏隐藏，都会停止当前笑声。
- 声音文件不可用或播放失败时保留静音桌宠；使用说明缺失或无法打开时给出提示，不会因此退出整个程序。

## 全屏自动隐藏

此功能默认开启，可通过右键菜单关闭。

- 仅针对奶蛙所在屏幕的前台全屏应用生效。
- 普通窗口最大化，以及其他屏幕上的全屏，不会触发隐藏。
- 退出全屏或切走该应用后，奶蛙回到原位置。
- 隐藏时正在播放的大笑会停止，恢复后回到待机。
- 如果隐藏前已经笑倒，恢复后仍会保留躺姿。

## 找不到奶蛙时

再次双击程序，或双击任务栏托盘中的奶蛙图标，让它回到鼠标所在屏幕的右下角。托盘图标可能收在任务栏的隐藏图标区域内。

如果此时仍处于全屏，奶蛙会继续隐藏。退出全屏，或在托盘右键菜单中取消「全屏时自动隐藏」，即可重新看到它。

## 素材处理说明

- 待机使用原始静态图片；二维追视只在可见眼睛内部做像素形变，眼轮廓、身体和透明度保持一致。关闭追视时使用原版转眼素材。
- 眨眼取自原视频第 47～58 帧中的七帧，仅作用于眼部。
- 大笑使用原视频第 79～500 帧，按原视频的 30 帧/秒播放。
- 戳肚子采用局部变形，脸部和脚部保持稳定；拖动和落地采用轻微旋转、缩放。
- 摸头使用原图局部变形与原版眨眼帧；投喂的纸张反馈由程序绘制，角色沿用原素材。
- 未使用生成式重绘，五官、体型、材质与颜色沿用原始素材。

## 设置保存位置

位置、大小、声音、置顶、全屏隐藏、目光跟随与投喂确认设置保存在：

```text
%LOCALAPPDATA%\NaiwaDesktopPet\settings.ini
```

可以将这一路径粘贴到 Windows 文件资源管理器的地址栏中打开。
